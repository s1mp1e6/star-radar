# 产品化路线图（PRODUCT）

> 定位：从「能用的 MVP」到「可公开运营的成熟产品」。
> 原则：每轮交付可见改进；先体验后功能；每轮自检 + 生产冒烟 + 用户验收。

## 基线评估（2026-08-14，诚实盘点）

**已具备**：功能闭环（抓取/存档/收藏/追踪/AI/排行）、四层架构、43 单测、5 份工程文档、
0 成本部署、审计可观测、回滚路径、双主题、响应式基础。

**差距**（用户反馈 + 自查）：
- 视觉：统一性不足、细节粗糙、首页无"产品感"
- 交互：key 保存误导（已修）、错误提示一闪而过（已修）、部分页面缺加载/空态
- 引导：新用户打开不知道先干什么
- 测试：无生产冒烟脚本，发布靠人工
- 功能：无通知推送、无统计报表、移动端未专门打磨
- 安全：无登录限流、无 CSRF 防护细节审计

## 工作流分项（W1~W6，按序执行）

### W1 视觉系统与发布自检（本轮）
- [ ] 首页 hero + 全站统计总览（存档天数/项目总数/收藏数）
- [ ] 全局视觉细节：标题层级、按钮态、卡片统一、版本号页脚
- [ ] scripts/smoke.mjs 生产冒烟脚本 + npm run smoke
- [ ] 发布流程固化：check → smoke(本地) → deploy → smoke(生产)

### W2 交互零死角 + 新手引导
- [ ] 五页面加载态（骨架屏）全覆盖
- [ ] 空态/错误态文案统一且有行动按钮
- [ ] 新手引导：首页空态三步行（令牌→AI→抓取）+ 设置页横幅（已上线）
- [ ] 收藏/删除/生成等操作的乐观反馈与失败恢复

### W3 移动端打磨（本轮完成 2026-08-14）
- [x] 375px 走查：顶栏导航横滑、卡片单列、表单全宽堆叠、排行 meta 换行
- [x] 触控目标：主导航/图标按钮 ≥44px、按钮 ≥40px、:active 按压反馈
- [x] safe-area：viewport-fit=cover + 顶栏/底栏/弹窗/toast 安全区适配
- [x] PWA：manifest + SVG 图标 + theme-color 动态同步（可添加到主屏）
- [x] **评估结论：不做 Service Worker 离线壳**——本产品核心数据全来自 API，离线状态无可用功能，SW 只会引入缓存失效事故；如需离线再看
- [x] 日报时段行移动端横滑

### W4 稳定性与安全加固
- [ ] 登录限流（/debug、写接口防爆破）
- [ ] 关键路径集成测试脚本化（抓取/AI mock/追踪/收藏全链路）
- [ ] 数据备份策略文档化（D1 Time Travel 演练）
- [ ] 异常监控：cron 连续失败告警（Console 通知）

### W5 高价值功能：通知推送
- [ ] 收藏项目新 release/大涨星 → 邮件或 Webhook 通知
- [ ] 日报推送（每日摘要，可选渠道）

### W6 高价值功能：统计报表
- [ ] 首页趋势图：每日项目数/星标总量曲线
- [ ] 收藏组合视图：总星标、涨幅 Top、语言分布

## 验收标准（每轮通用）

1. npm run check 全绿；2. 本地冒烟全过；3. 生产 smoke 全过；
4. 改动点有截图级描述（用户可直接验证）；5. CHANGELOG 更新；
6. 用户确认"这一轮体感变好了"才算过。

## 版本节奏

打磨期 0.1.x（每轮 +0.0.1）；W5/W6 新功能完成后升 0.2.0；
体验与功能被用户认可后升 1.0.0（正式版，对外公开运营）。
