## 桌面演练 #1：抓取失败（PLAYBOOK 故障 #1）

- **检测**：cron_runs 出现 status=error + error_msg（如 rate_limited(403)/http_422）；/debug 可见
- **响应**：本轮实测——422 时 audit 如实记录并终止（不误重试）；次日 06:00/21:00 触发时 hasCompletedRun=false → 自动补抓；或 POST /admin/trigger {task:scrape} 手动补
- **回滚**：无需回滚（无副作用写入）；若入库了脏数据 → D1 Time Travel
- **演练结论**：✅ 通过（本阶段真实故障已按此路径处理并恢复）
