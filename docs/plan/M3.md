## 落地的前端工程决策（对应旧方案已知问题）

- #16 30s localStorage 缓存：`apiGet` 先回旧数据 + 后台静默刷新
- #17 事件总线：写操作后 `sr-data-changed` 广播 + 缓存失效，同页面实时同步
- #27 防白闪：每页 head 内联主题脚本（先于 CSS 渲染）
- A3 深链：排行榜/收藏跳日报自动展开详情（`?autorepo=`），daily.js 已处理
- 安全：前端 Token 只存 localStorage，写操作统一带 X-Admin-Token，401 统一引导去设置页
